它是一个「会话记忆 / 上下文管理」工具：你说一句「记录」，它就把当前对话的“全量原文”“（包括生成出来的图片、代码、HTML 等）存档到 D:\Mark；以后说「回忆」，它就能从这些档案里”精准找回”前面说过的话和做过的产出。

一 它解决什么问题
     AI 对话越长、越跨会话，前面的内容就越容易「忘记和混乱」。这个 skill 用一套.md文件做长期记忆，让后面的对话（同一个 AI 或另一个 AI）能翻回前  面讲过什么、产出过什么。

二 HOW TO USE（TWO WAYS）
使用说明：
     1.DO IT YOUSELF（使用触发词）
     「记录」/「存档」/「记住」| 把当前对话分段写进 D:\Mark，生成物归档，更新索引 （ps：类似的话就行）
     「 回忆 …」** | 按索引定位到具体文件，用原文精准回答，并告诉你出处 |
     2.AUTO
     大约每150k token记录一次

三 WHERE
文件存到哪、长什么样？
     一般是指定D:\Mark里面，可能需要提前创建一个...
     D:\Mark\
     ├─ index.md                          ← 总索引（先看它找文件夹）
     └─ 2026-09-06-1830-记忆skill设计\     ← 每次对话一个文件夹
          ├─ index.md                     ← 本次对话的索引
          ├─ 001.md                       ← 第 1 段原文（约 ≤150k token）
          ├─ 001-assets\                  ← 这段里的图片/代码/HTML
          ├─ 002.md                       ← 第 2 段（只记新内容，不重复）
          └─ ...
     
核心设计要点（为什么这么设计）
     全量原文 + 分段：要「精准回忆」就得存原文，但原文太长读不回来，所以按 ~150k token 切一段，段头写摘要+关键词。
     非重叠增量：每段只装新内容，不重复写，省空间。
     分块写入：一大段拆成多批写，避免中途截断、丢内容。
     两级索引：总索引 → 会话索引 → 分段原文，像「目录 → 章节 → 正文」，先索引后原文。
     生成物归档：图片塞不进 MD，就复制成文件放 -assets 文件夹，MD 里记路径+说明。
     任何 AI 都能用：不依赖任何平台内置记忆，全靠普通文件 + 索引头部的「使用说明」，换任何 AI 读 index 都能照做。
